# Changelog

All notable changes to this project are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

- Prepare public documentation, CI, security policy and package metadata.

## [0.1.0] - 2026-07-15

- Introduce rolling route/month discovery with persistent scan state.
- Add robust median/MAD baselines and persistent alert deduplication.
- Add optional Duffel and LiteAPI live repricing.
- Add calendar-aware seasonal, weekend and public-holiday windows.
- Add Telegram/email delivery, health checks and Docker deployment.
- Adopt shared resilience and runtime primitives from `radar-core`.
